# Company API

A Java-based REST API for managing company operations and data.

## 📋 Overview

This repository contains a backend API service built with Java for handling company-related operations. The project is designed to provide robust endpoints for managing various company resources and business logic.

## 🛠 Tech Stack

- **Java** (94.6%) - Core backend language
- **HTML** (5.4%) - Frontend documentation/UI components

## 🚀 Getting Started

### Prerequisites

- Java 8 or higher
- Maven or Gradle (depending on build configuration)
- Git

### Installation

1. Clone the repository:
```bash
git clone https://github.com/ShriramMapalakaje/company-api.git
cd company-api
```

2. Build the project:
```bash
# Using Maven
mvn clean install

# Using Gradle
gradle build
```

3. Run the application:
```bash
# Using Maven
mvn spring-boot:run

# Using Gradle
gradle bootRun
```
